# Build FlowBoard: A Drag and Drop Task Manager

### Description
You are going to build FlowBoard, a clean and modern Kanban board. It has three columns: Todo, In Progress, and Done. Users can create new task cards, type in a title and a little description, and then drag those cards between columns as their work moves forward. Every task gets saved to a real cloud database, so nothing disappears when you refresh the page.

## Tech Stack

- React (TypeScript)
- Supabase
- TailwindCSS
